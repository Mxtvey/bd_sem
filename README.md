# bd_sem



# База данных "Library"

База данных предназначена для хранения информации о работе библиотеки: книгах, авторах, филиалах, читателях и их взаимодействиях.  



## Как устроен проект?

В папке data_models лежат 3 модели данных : концептуальная, логическая , физическая

В scripts лежат скприты создания таблиц , наполниения их данными , разбиение на табличные пространства и сземы


## Схемы базы данных

| Схема | Назначение |
|--------|-------------|
| **catalog** | хранит данные о книгах, авторах, жанрах и языках |
| **library** | хранит данные о филиалах, полках и экземплярах книг |
| **users** | хранит данные о читателях, профилях и выдачах |


## Табличные пространства

| Tablespace | Назначение |
|-------------|-------------|
| **fast_data** | хранение таблиц, связанных с каталогом и структурой библиотеки |
| **user_data** | хранение таблиц, связанных с пользователями и выдачами |



## Модели данных

- **Концептуальная модель** — отражает основные сущности предметной области и связи между ними.  
- **Логическая модель** — уточняет структуру данных, добавляет атрибуты, ключи и ограничения.  
- **Физическая модель** — описывает реализацию таблиц в PostgreSQL с учетом схем и tablespace.
